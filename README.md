# Смешарики для Minecraft: набор модов (демо)

Некоммерческий фан-проект: набор модов Fabric для Minecraft 26.2, в котором можно поиграть за Кроша и Ёжика и пройти уровень «Большое маленькое приключение» (пять миссий: от утра до погони) — в одиночку с напарником или вдвоём. Подробности о правах — в [NOTICE.md](NOTICE.md).

> Это демо-версия: один уровень, один мир, без собственной музыки в игре. Всё может меняться.

## Что в наборе

| Мод | Что делает |
|---|---|
| **GameplayMod** | персонажи (вселение, одежда, способности), тарзанки, плоты, воздушный шар, ветер, лава, обстрелы, жерла |
| **WorldMod** | типы мира «Остров Смешариков» и «Мир-океан», шейдерпак, река с брёвнами |
| **BehaviorMod** | напарник и приказы, окно реплик, кат-сцены (запись, редактор, показ) |
| **LevelMod** | уровни, миссии, задачи, чекпоинты, редактор уровней, список задач на экране |
| **BuildMod** | строитель (только творческий режим): формы, постройки, покраска, платформы, стены |
| **SmesharikiMod** | установка модов с хоста и с GitHub, версии мира, переключатель проверки аккаунтов |

Каждый мод — отдельный репозиторий со своим README. Карта проекта и правила разработки — [CLAUDE.md](CLAUDE.md), проверки — [docs/](docs/).

## Что нужно

- Minecraft **26.2**, Java **25**;
- [Fabric Loader](https://fabricmc.net/use/installer/) и [Fabric API](https://modrinth.com/mod/fabric-api) `0.161.0+26.2`;
- по желанию [Sodium](https://modrinth.com/mod/sodium) и [Iris](https://modrinth.com/mod/iris) (шейдеры).

Минимум по памяти: рабочий мир открывается при `-Xmx2G`, комфортнее 4 ГБ.

## Установка

**Способ 1 (проще): через SmesharikiMod.**
1. Установите Fabric для 26.2 и положите в папку `mods` два файла: [Fabric API](https://modrinth.com/mod/fabric-api) `0.161.0+26.2` и `smesharikimod-1.0.0.jar` из [последнего релиза](https://github.com/NoPasaRun/smeshariki-demo/releases/latest).
2. Запустите игру: на экране заголовка появится окно «Установка с GitHub» со списком файлов. Нажмите «Скачать и установить» (моды — исполняемый код, ставьте только если доверяете источнику). Установятся остальные моды и мир «Ромашковая Долина». Репозиторий задан в `config/smesharikimod.json` (`gitRepo`, по умолчанию `NoPasaRun/smeshariki-demo`).
3. Перезапустите игру.

**Способ 2: вручную.** Скачайте из релиза все `.jar` в `mods` (и Fabric API отдельно), а `world.zip` распакуйте в папку `saves`.

## Как играть

1. Откройте мир **«Ромашковая Долина»** в режиме выживания. При входе выберите персонажа (Крош или Ёжик).
2. Клавиша **L** открывает окно уровней, там «Начать» (для одного игрока второго персонажа ведёт напарник). Клавиша **U** — описание миссии, **Y** — показать или скрыть стрелку к цели, **J** — реплики напарнику.
3. **Вдвоём:** хост открывает мир для сети (Esc → «Открыть для сети»), второй игрок ставит SmesharikiMod и при входе подтверждает установку модов с хоста; каждый берёт своего персонажа. Если у хоста выключена проверка аккаунтов, зайти можно под любым ником.

Остальные клавиши — в `docs/keys.md`. Строитель (B) и версии мира (V) работают только в творческом режиме.

## Известные ограничения

- Один уровень и одна локация; музыки в самой игре нет (поддержка своих `.mp3` в кат-сценах есть).
- Установка модов с хоста для гостя описана в SmesharikiMod; проверялась в основном автоматически, на двух настоящих клиентах — нет.
- Если один из двоих вышел посреди миссии, второй не может её закончить (роль остаётся за вышедшим): можно бросить уровень или дождаться возвращения.

## Для разработчиков

- Сборка: порядок и команды — в [CLAUDE.md](CLAUDE.md); у каждого мода свой `./gradlew jar`.
- Проверки без игры: [docs/smoke-test](docs/smoke-test) (запуск и все окна), [docs/level-sim](docs/level-sim) (прогон уровня на двоих, установка с GitHub).
- Мир и релиз: `SmesharikiMod/tools/export_world.py` (чистая копия мира) и `SmesharikiMod/tools/release.py` (сборка и публикация релиза).
