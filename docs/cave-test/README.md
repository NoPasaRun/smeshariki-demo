# Проверка 4-й миссии (cave) на копии настоящего мира (клиентский gametest)

Копирует мир «Ромашковая Долина» (2,4 ГБ) из `~/.minecraft/saves` и файлы уровней/локаций из `~/.minecraft/data/levelmod`, открывает копию, ставит игрока у начала пещеры, запускает проверку миссии **тем же JSON, что шлёт редактор** (`LevelDraft` → `LevelTestTask`), вселяет Ёжика и пишет в лог строки `CAVE`: события прогона, когда пошла каждая волна лавы, гибели. Убивает персонажа через 100 тиков после `lava1`, всего 5 попыток.

```
cd docs/cave-test
./gradlew runClientGameTest --no-daemon -Dorg.gradle.jvmargs=-Xmx900m > run.log 2>&1
grep -E "CAVE (---|итог|diag)|WAVE|MARKER" run.log
```

Ожидаемо: `lava1` пошла через ~300 тиков после старта (100 отсчёта + 200 задержки) и через ~305 после каждой гибели. Перед запуском собрать моды и положить jar в `~/.minecraft/mods`, игра закрыта (память 7,2 ГБ). Мир копируется заново при каждом запуске; настоящий мир не меняется.
