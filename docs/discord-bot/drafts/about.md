**Ромашковая Долина** 🌼 Моды для Minecraft по мотивам «Смешариков»

Некоммерческий фан-проект: набор модов Fabric для Minecraft 26.2. Мы строим большую приключенческую игру с сюжетом по мотивам мультсериала «Начало», а пока выпускаем играбельное демо.

**Что уже можно попробовать (демо):**
• мир «Ромашковая Долина» и уровень «Большое маленькое приключение» из пяти миссий: от утра до погони;
• Крош и Ёжик: можно играть одному (второго ведёт напарник) или вдвоём по сети;
• тарзанки, плоты на течении, воздушный шар, лава, кат-сцены с репликами;
• редактор уровней и строитель для творческого режима.

**Как присоединиться:** установка за пару минут, инструкция в <#1571454566149394462>. Нашли баг? Форум <#1571177339180814346>. Есть идея? Форум <#1571487077873229864>.
