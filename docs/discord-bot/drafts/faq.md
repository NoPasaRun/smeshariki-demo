**Частые вопросы**

**Что нужно для игры?** Minecraft 26.2, Java 25, Fabric и Fabric API 0.161.0+26.2. По желанию Sodium и Iris (шейдеры). Памяти минимум 2 ГБ, комфортнее 4 ГБ.

**Можно играть одному?** Да, второго смешарика ведёт напарник. Приказы напарнику: клавиша **J** (реплики).

**Как играть вдвоём?** Хост открывает мир для сети (Esc → «Открыть для сети»). Второй игрок ставит SmesharikiMod и при входе подтверждает установку модов с хоста. Каждый берёт своего персонажа.

**Какие клавиши?** **L** окно уровней («Начать»), **U** описание миссии, **Y** показать или скрыть стрелку к цели, **J** реплики. Остальные есть в `docs/keys.md` репозитория.

**Я поставил блоки во время уровня, а после они пропали.** Так задумано: в выживании мир после уровня откатывается. Строить и сохранять постройки можно в творческом режиме, версии мира (клавиша **V**) тоже только там.

**Что если один из двоих вышел посреди миссии?** Сейчас второй не может её закончить: можно бросить уровень или дождаться возвращения. Мы знаем об этом.

**Почему нет музыки?** В демо нет своей музыки в игре. Свои `.mp3` в кат-сценах поддерживаются.

**Игра вылетает или не запускается?** Сначала <#1571454566149394462>: там частые причины (старые файлы модов, моды из разных релизов). Не помогло: пост в <#1571177339180814346> по шаблону, с логом.

**Это бесплатно?** Да, проект некоммерческий. Код под MIT, всё, что связано со «Смешариками», этой лицензией не покрывается.
