**Выберите роль** 🎭

**Есть GitHub?** Нажмите **«У меня есть GitHub»** и введите ник. Бот выдаст короткий код: впишите его в поле Bio профиля GitHub, чтобы подтвердить, что аккаунт ваш, и нажмите кнопку снова. Если у вас есть свой проект на Java (форки не считаются), вы получите роль **Разработчик** и откроются рабочие каналы. Если у вас есть коммиты в репозиториях проекта, получите **Контрибьютор**.

**Нет GitHub или нужна другая роль?** Нажмите **«GitHub нет / другая роль»**: «Игрок» выдаётся сразу, строитель, сценарист, постановщик, тестировщик и дизайнер одобряют админы.
